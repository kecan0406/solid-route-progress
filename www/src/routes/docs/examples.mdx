# Examples

Each demo is a real component, and the code under it is that component's file, imported with `?raw`. Every bar sits in its own panel (the [container recipe](/docs/styling#inside-a-container)) and passes `busyAttribute={false}`.

## `track()`

| Button             | Result                                                     |
| ------------------ | ---------------------------------------------------------- |
| Fetch (1.5 s)       | holds, then completes                                      |
| Fail it (1.2 s)     | releases as `'error'`, sets `data-error`, and turns [red](/docs/styling#failed-loads) |
| Too fast (120 ms)   | shorter than `delay`, so it is never painted               |

<Example source={trackPromiseSource}>
  <TrackPromise />
</Example>

## `start()` and `release()`

| Button             | Result                                    |
| ------------------ | ----------------------------------------- |
| Take a hold        | one more hold                             |
| Release one        | bar keeps going until the last hold goes  |
| Release as cancel  | fades out without reaching 100%           |
| Release as error   | completes with `data-error`               |

## Skipping navigations

Both bars are wired to this page's router. The links only change the search string.

| Link           | default + `filter` | `shallow` |
| -------------- | ------------------ | --------- |
| `?skip=go`     | flashes            | ignores   |
| `?skip=blocked` | `filter` returns `false` | ignores   |
| `?skip=quiet`  | `data-sp-ignore`   | ignores   |
