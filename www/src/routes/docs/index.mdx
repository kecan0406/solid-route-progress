# Introduction

```tsx
import { Router } from '@solidjs/router'
import { Suspense } from 'solid-js'
import { RouteProgress } from 'sprogress/router'
import 'sprogress/style.css'

<Router
  root={(props) => (
    <>
      <RouteProgress />
      <Suspense>{props.children}</Suspense>
    </>
  )}
/>
```

## Entry points

| Entry                  | Exports                                                                       |
| ---------------------- | ----------------------------------------------------------------------------- |
| `sprogress`            | `createProgress`, `<Progress>`, `<ProgressProvider>`, `<Bar>`, `useProgress()` |
| `sprogress/router`     | `<RouteProgress>`, `createRouteProgress()`                                    |
| `sprogress/navigation` | `<NavigationProgress>`, `createNavigationProgress()`                          |
| `sprogress`            | `createCrossDocumentProgress()`, `IGNORE_ATTRIBUTE`                           |
| `sprogress/style.css`  | the stylesheet                                                                |

## What JavaScript writes

| Written             | On               | Value                                    |
| ------------------- | ---------------- | ---------------------------------------- |
| `--sp-value`        | the bar          | `0` to `1`, the target of the CSS transition |
| `--sp-speed`        | the bar          | the `speed` option                       |
| `data-state`        | the bar          | `idle \| trickle \| active \| done`      |
| `data-error`        | the bar          | during the done phase of a failed load   |
| `data-sp-busy`      | `<html>`         | while any bar is visible                 |

Everything else is CSS.
